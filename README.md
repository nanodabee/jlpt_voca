# JLPT 일본어 단어장 — 비밀번호 없는 서버 버전

- 회원가입/PIN/비밀번호 없음
- 접속하면 바로 단어장 화면 표시
- 단어, 학습 기록, 오답, 회독, 설정을 서버 SQLite DB에 저장
- JSON 백업 내보내기/불러오기
- YouTube 링크 자막 가져오기

## Windows 로컬 실행
1. Python 3.11 이상 설치
2. `start.bat` 실행
3. 브라우저에서 `http://127.0.0.1:8000` 접속

현재 패키지는 로컬 서버 실행용입니다. 실제 인터넷 서버에 배포하면 휴대폰 Safari 등에서도 같은 주소로 접속할 수 있습니다.

## 주의
인터넷에 공개 배포하면서 인증을 사용하지 않으면 URL에 접근할 수 있는 사람이 데이터를 볼 수 있습니다. 개인적인 테스트나 접근이 제한된 환경에서 사용하는 것을 권장합니다.
